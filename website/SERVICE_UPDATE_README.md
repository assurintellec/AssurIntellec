# AssurIntellec — Seven Service Page Update

The original site and Decap Turbo backend are retained. All seven service pages now use the new responsive 16:9 hero and content card design.

## Edit in Decap Turbo
Go to **Services → All 7 Services**, select a service, and edit Hero Media Type (image/video), Hero Image, Hero Video, text, sections, section photos, typography, animation toggle and email. Publish to update `content/services.json`.

## Images and video
Existing bundled website photos are used as initial illustrative placeholders across the expanded cards. Replace these in Decap with accurate, licensed, service-specific photographs. No new stock photos or videos are claimed to have been supplied. Video must be uploaded and selected in the Hero Media Type control; existing hero images are used by default.

## Deployment
Upload the contents of `AssurIntellec-main` to the same GitHub repository/branch currently serving the website. Preserve `admin/config.yml` backend credentials/settings. Test Decap publishing on the deployed domain; local file checks cannot verify external permissions.
